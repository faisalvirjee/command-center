Bracket Marker Lexicon — Cheat Sheet

v1.0 · 2026-04-29
Canonical short codes used inside item titles. Format: Title # N [code, code, code] — codes ordered by category number below. Brackets are only at the end of the title. Comma-separated. Codes are case-insensitive but the parser stores them as written.

B.Cleanup pass sequence

1. Edition flags V / F / T / E. Highest signal-to-noise. After this pass alone you can filter Foils vs Virgins vs Trades — biggest immediate ROI for the smallest effort.
2. Format / Print HC / TPB / RIP / 1ST / RP. Most rows are blank here — format markers only apply to specific items. Quick scan pass.
3. Signed family SIG / SIG xN / SKETCH / REMARQUE. Already partially extracted by sanitizer — mostly verifying and adding signer names in the Signed By field separately.
4. Raw grade NM / NM+ / VF / VG / etc. on raw books only. Skip slabbed (gradingCo field handles those). Personal note for tracking real condition.
5. Limited / Ratio LTD N and R 1:N. Slowest pass — requires looking up print runs and ratio numbers. Save for last when the rest is locked in.

C.Ground rules

Position

Brackets always at the end of the title. Never embedded mid-string.

Order

Codes follow category number — Edition (01) first, then Format (02), Print (03), Signed (04), Grade (05), Limited (06).

Separator

Comma + space between codes. Square brackets only.

Slab

Don't add SLAB. Grading Co field is the source of truth — Slab badge auto-populates from there.

Signer name

SIG flags presence only. Put the actual signer name in the Signed By field, not in the bracket.

Co-existable

Most codes stack freely. A book can be V + F + SIG + LTD all at once. Just respect category order.
